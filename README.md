## 🧮 Projeto atual: Matemática Básica

Atualmente, o repositório conta com um projeto voltado para o aprendizado da **tabuada de multiplicação**.

A ideia é simples: praticar até conseguir responder às multiplicações de forma rápida e automática, deixando as respostas *na ponta da língua*.

### 💭 Pense rápido!

- Quanto é `9 × 6`?
- Quanto é `5 × 5`?
- Quanto é `7 × 8`?

Você respondeu imediatamente ou precisou fazer algumas contas mentalmente?

Por exemplo, para calcular `5 × 5`, você poderia pensar:

1. `5 × 2 = 10`
2. `5 × 4 = 20`
3. `20 + 5 = 25`

> O resultado está correto, mas o objetivo é não precisar reconstruir o cálculo toda vez que encontrar uma multiplicação.

### 🎯 Objetivo

Desenvolver agilidade e familiaridade com a tabuada por meio de exercícios simples e divertidos, tornando os cálculos básicos cada vez mais naturais.
